One-time setup: Apple's Dictionary Development Kit

StarDict2Mac uses Apple's free Dictionary Development Kit for the final build step. Apple's terms don't allow including it in other apps, so it's set up once, separately:

The download comes from a public copy of the kit in Apple's “Additional Tools for Xcode 14.1”; every file is checked against a known fingerprint before it is used. Prefer Apple's own download? Get Additional Tools for Xcode (free Apple ID), open it, and choose its Utilities › Dictionary Development Kit folder.
